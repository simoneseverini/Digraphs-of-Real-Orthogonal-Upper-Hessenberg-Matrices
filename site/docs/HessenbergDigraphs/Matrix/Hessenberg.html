    Upper Hessenberg matrices #

    A square matrix is upper Hessenberg if every entry strictly below the first subdiagonal is zero. It is unreduced if additionally every subdiagonal entry is non-zero.

    The two predicates underlie the QR algorithm and the classification of support digraphs of orthogonal Hessenberg matrices.

    Main definitions #

    • Matrix.IsUpperHessenberg M — M i j = 0 whenever j + 1 < i.
    • Matrix.IsUnreduced M — upper Hessenberg with non-vanishing subdiagonal.

    References #

    Golub & Van Loan, Matrix Computations (4th ed.), §7.4. Severini, "Digraphs of Real Orthogonal Upper Hessenberg Matrices" — §1.

      def Matrix.IsUnreduced {n : ℕ} (M : Matrix (Fin n) (Fin n) ℝ) :
      Prop

      Math. An upper Hessenberg matrix is unreduced if all subdiagonal entries are non-zero, i.e. M (i + 1) i ≠ 0 for all valid i.

      Equations
      • M.IsUnreduced = (M.IsUpperHessenberg ∧ ∀ (i : Fin n) (h : ↑i + 1 < n), M ⟨↑i + 1, h⟩ i ≠ 0)
