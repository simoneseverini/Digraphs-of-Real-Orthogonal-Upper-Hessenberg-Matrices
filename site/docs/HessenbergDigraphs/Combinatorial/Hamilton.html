    Directed Hamilton cycle in D_n(S) #

    Every D_n(S) contains the directed Hamilton cycle H : 1 → n → (n - 1) → ⋯ → 2 → 1 regardless of S. Migrated to Foundation API: S : ActiveSet n, vertices in Vertex n, arcs via the inductive Arc S i j.

    Main results #

    • HCycleArc n i j — predicate isolating the arcs of H.
    • hcycle_subset — every arc of H is an arc of D_n(S) (Paper: Lemma 8).
    • hamiltonDistance — the directed distance between two vertices along the Hamilton cycle.

    References #

    Severini, "Digraphs of Real Orthogonal Upper Hessenberg Matrices" — Lemma 8.
