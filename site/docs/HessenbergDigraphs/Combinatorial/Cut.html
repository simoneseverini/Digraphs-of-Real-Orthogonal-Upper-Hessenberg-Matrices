    theorem HessenbergDigraphs.backward_arc_is_spine {n : ℕ} (S : ActiveSet n) (i j : Vertex n) (harc : Arc S i j) (hij : j.value < i.value) :
    ∃ (h : j.value < n), i = j.next h

    Math. An arc (i, j) with j.value < i.value is a spine arc.

    theorem HessenbergDigraphs.cut_lemma {n : ℕ} (S : ActiveSet n) (k : ℕ) (i j : Vertex n) (harc : Arc S i j) (hi : k + 1 ≤ i.value) (hj : j.value ≤ k) :
    i.value = k + 1 ∧ j.value = k

    Math. The only arc of D_n(S) crossing the cut from {k+1, …, n} down to {1, …, k} is the spine arc (k+1, k).

    theorem HessenbergDigraphs.inDeg_mem_S {n : ℕ} (S : ActiveSet n) (j : Vertex n) (hn : 2 ≤ n) (hjS : ∃ k ∈ S.elements, k.value = j.value) :
    inDeg S j = 1 + ({k ∈ S.elements | k.value < j.value}.card + 1)

    Math. For j corresponding to an element of S, the in-degree of j in D_n(S) equals 2 + |elements with value < j.value|.
