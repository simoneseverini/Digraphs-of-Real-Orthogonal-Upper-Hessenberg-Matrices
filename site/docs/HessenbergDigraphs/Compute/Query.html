              theorem HessenbergDigraphs.mem_degreeList_iff {n : ℕ} (S : ActiveSet n) (a od id : ℕ) :
              (a, od, id) ∈ S.degreeList ↔ ∃ (v : Vertex n), v.value = a ∧ outDeg S v = od ∧ inDeg S v = id

              Math. degreeList lists exactly the formal degrees: (a, od, id) occurs iff a = v.value, od = outDeg S v, id = inDeg S v for some vertex v of D_n(S).

              theorem HessenbergDigraphs.isLoopless_iff {n : ℕ} (S : ActiveSet n) :
              S.isLoopless = true ↔ ∀ (v : Vertex n), ¬Arc S v v

              Math. isLoopless decides exactly the formal loopless property: S.isLoopless = true iff D_n(S) carries no self-loop Arc S v v. Together with loopless_iff this certifies the calculator's loopless verdict.

              theorem HessenbergDigraphs.countClasses_eq_card_isoClasses {n : ℕ} (hn : 2 ≤ n) :
              countClasses n = (Finset.image isoInvariant Finset.univ).card

              Math. Specification of the classification count: the calculator's output countClasses n equals the number of isomorphism classes of D_n(S) — the distinct values of the complete invariant isoInvariant (card_isoClasses, with completeness isoInvariant_eq_iff). Paper: Theorem 12.

              theorem HessenbergDigraphs.countClasses_eq_isoQuot {n : ℕ} (hn : 2 ≤ n) :
              countClasses n = Nat.card (Quotient (isoSetoid n))

              Math. Stronger specification of the classification count as a genuine cardinality: the calculator's output countClasses n equals the number of isomorphism classes of D_n(S), i.e. the cardinality of the quotient of active sets by support-digraph isomorphism (isoSetoid). Unlike countClasses_eq_card_isoClasses — which only equates the count to the size of isoInvariant's image — this routes through card_isoClasses_quot, whose proof uses the rigidity theorem rigid (via isoInvariant_eq_iff) to certify that isoInvariant is a complete invariant. So this is the honest iso-class count. Paper: Theorem 12.
