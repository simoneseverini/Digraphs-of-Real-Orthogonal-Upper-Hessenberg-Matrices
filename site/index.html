Digraphs of real orthogonal upper Hessenberg matrices

Verso Blueprint GitHub

This project gives a complete classification, formalised in Lean 4 on top of Mathlib, of the support digraphs of real orthogonal upper Hessenberg matrices. The support digraph $D(Q)$ of a matrix $Q \in \mathbb{R}^{n\times n}$ is the directed graph on $[n]$ with an arc $i \to j$ whenever $Q_{ij} \ne 0$.

The main result. An unreduced $Q \in \mathcal{H}_n$ is sign-equivalent to a canonical Givens product $Q_n(\theta)$, and the support digraph of that product is determined by an active set $S \subseteq [n-1]$. Up to digraph isomorphism, the connected support digraphs on $n$ vertices are enumerated by

$$N_n \;=\; 2^{\,n-1} \;-\; \lfloor (n-1)/2 \rfloor.$$

A loopless restriction reduces this to $F_{n-1} - \lfloor (n-3)/2 \rfloor$, with $F_k$ the $k$-th Fibonacci number. The four pillar theorems — universality, bridge, rigidity, and the apex classification — and the two enumeration counts are formalised with zero sorry and depend only on Lean 4's three standard axioms.

Main theorem

The Lean apex declaration assembles realisability, the matrix / combinatorial bridge, and the rigidity of the active-set family:

theorem classification {n : ℕ} (hn : 2 ≤ n) :
    (∀ S : ActiveSet n, ∃ θ : UnreducedAngles n, θ.activeSet = S) ∧
    (∀ θ : UnreducedAngles n, θ.product.supportDigraph = θ.activeSet.digraph) ∧
    (∀ S S' : ActiveSet n, 2 ≤ S.elements.card → 2 ≤ S'.elements.card →
        S.digraph ≅ S'.digraph → S = S') :=
  ⟨completeness, digraph_model hn, fun S S' => rigid S S' hn⟩

The signature reads as a paper sentence: every active set is realised; the support of every Givens product equals the active-set digraph; and isomorphic active-set digraphs of size $\ge 2$ are equal.

Rigidity

The combinatorial heart of the classification. Every isomorphism between $D_n(S)$ and $D_n(S')$ with $|S|, |S'| \ge 2$ fixes the unique directed Hamilton cycle and forces $S = S'$.

theorem rigid {n : ℕ} (S S' : ActiveSet n) (hn : 2 ≤ n)
    (hcard : 2 ≤ S.elements.card) (hcard' : 2 ≤ S'.elements.card)
    (hiso : S.digraph ≅ S'.digraph) : S = S'

Counting the classes

The enumeration is a genuine cardinality, not merely an arithmetic identity: the active sets modulo digraph isomorphism number exactly $N_n$. The quotient is formed by the isomorphism relation directly.

theorem card_isoClasses_quot {n : ℕ} (hn : 2 ≤ n) :
    Nat.card (Quotient (isoSetoid n)) = 2 ^ (n - 1) - (n - 1) / 2

The quotient of active sets by digraph isomorphism (isoSetoid) has exactly $2^{n-1} - \lfloor (n-1)/2 \rfloor$ elements; the loopless restriction is $F_{n-1} - \lfloor (n-3)/2 \rfloor$ (card_looplessClasses_quot). Paper: Theorems 12 and 15.
