1 Setup and definitions

We work with \(n \times n\) real matrices (\(n \ge 2\)), indexed by \([n] = \{ 1, 2, \dots , n\} \) throughout. The five definitions below set up both the matrix-side object of study (orthogonal upper Hessenberg matrices), its combinatorial shadow (the support digraph), and the two parameterisations (Givens factorisation, active set) that allow the matrix and combinatorial sides to be compared.

  • HessenbergDigraphs.OrthogonalHessenberg

A matrix \(Q \in \mathbb {R}^{n\times n}\) is upper Hessenberg if \(Q_{ij} = 0\) whenever \(j+1 {\lt} i\), and orthogonal if \(Q^\top Q = I\). We write \(\mathcal H_n\) for the set of orthogonal upper Hessenberg matrices in \(\mathbb {R}^{n\times n}\).

  • HessenbergDigraphs.OrthogonalHessenberg.supportDigraph

The support digraph of \(Q\), denoted \(D(Q)\), is the directed graph on \([n]\) with an arc \(i \to j\) whenever \(Q_{ij} \ne 0\). The classification problem is to describe, up to digraph isomorphism, the set \(\{ D(Q) : Q \in \mathcal H_n\} \).

Definition 3
✓

Lean declarations

  • Matrix.SignEquiv

Two matrices \(Q, Q' \in \mathbb {R}^{n\times n}\) are sign-equivalent, written \(Q \simeq _{\mathrm{sign}} Q'\), if \(Q' = D_L Q D_R\) for some diagonal matrices \(D_L, D_R\) with entries in \(\{ \pm 1\} \). Sign-equivalent matrices have identical zero / non-zero patterns, so \(D(Q) = D(Q')\).

Definition 4
✓
#

Lean declarations

  • Matrix.givensRotation
  • Matrix.givensProduct

For \(k \in \{ 0,\dots ,n-2\} \) and \(\theta \in \mathbb {R}\), the Givens rotation \(G_k(\theta ) \in \mathbb {R}^{n\times n}\) is the identity with the \(2\times 2\) block at rows / columns \((k, k+1)\) replaced by \(\bigl[\begin{smallmatrix} \cos \theta & -\sin \theta \\ \sin \theta & \cos \theta \end{smallmatrix}\bigr]\). The ordered Givens product of an angle vector \(\theta = (\theta _0, \dots , \theta _{n-2})\) is \(Q_n(\theta ) := G_0(\theta _0) G_1(\theta _1) \cdots G_{n-2}(\theta _{n-2})\). An angle vector is called unreduced if every \(\sin \theta _k\) is non-zero; we write \(\Theta _n\) for the set of such vectors.

  • HessenbergDigraphs.ActiveSet
  • HessenbergDigraphs.Arc

For \(\theta \in \Theta _n\), the active set is \(S(\theta ) := \{ k \in [n-1] : \cos \theta _{k-1} \ne 0\} \). For any \(S \subseteq [n-1]\), set \(R(S) := \{ 1\} \cup \{ k+1 : k \in S\} \) and \(C(S) := S \cup \{ n\} \), and define \(D_n(S)\) on \([n]\) to have arcs \(j+1 \to j\) for \(1 \le j \le n-1\) (spine) plus \(i \to j\) whenever \(i \in R(S)\), \(j \in C(S)\), \(i \le j\) (overlay).
